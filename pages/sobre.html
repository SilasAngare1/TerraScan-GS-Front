Sobre o TerraScan

Informações sobre o sistema de monitoramento ambiental.

O que é o TerraScan?

O TerraScan é um sistema de monitoramento ambiental criado para acompanhar ocorrências como queimadas, desmatamento e poluição hídrica em regiões monitoradas.

Objetivo do Projeto

O objetivo é organizar informações ambientais em um painel simples de consultar, ajudando na análise de áreas críticas e no acompanhamento dos eventos registrados.

O que o projeto reúne

A plataforma reúne páginas de dashboard, mapas, eventos e relatórios para apresentar os dados ambientais de forma organizada e fácil de consultar.

Proposta de uso

O TerraScan pode ser usado como base para estudos, apresentações e simulações relacionadas ao acompanhamento de impactos ambientais em diferentes regiões.

Sobre o Projeto

O projeto TerraScan foi desenvolvido como uma proposta de apoio ao monitoramento ambiental, reunindo em uma única interface dados sobre ocorrências, regiões afetadas e relatórios de acompanhamento.

A ideia central é facilitar a visualização de informações ambientais e tornar a consulta dos registros mais clara para estudantes, pesquisadores e equipes que precisam acompanhar impactos em diferentes áreas.

A ideia surgiu da necessidade de tornar esses dados mais acessíveis e fáceis de interpretar. Em vez de deixar as informações espalhadas, o projeto propõe uma forma simples de reunir alertas, mapas, eventos e relatórios.

Como solução, o TerraScan apresenta uma interface web para consultar ocorrências ambientais, acompanhar áreas monitoradas e visualizar relatórios. Com isso, o usuário consegue entender melhor quais regiões precisam de mais atenção.
