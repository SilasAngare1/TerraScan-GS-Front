# TerraScan

O TerraScan é um projeto de interface web voltado ao monitoramento ambiental. A proposta é organizar informações sobre queimadas, desmatamento, poluição hídrica e regiões monitoradas em páginas simples de consultar.

O objetivo do projeto é facilitar a visualização de dados ambientais, reunindo dashboard, mapas, eventos, relatórios, FAQ, contato, integrantes e informações sobre o projeto em um mesmo sistema.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Git e GitHub

## Páginas do projeto

- `index.html`: tela inicial de login.
- `dashboard.html`: visão geral com indicadores, gráfico, mapa e eventos recentes.
- `map.html`: página para visualização de eventos ambientais por região.
- `events.html`: listagem e consulta de eventos ambientais.
- `reports.html`: consulta de relatórios ambientais.
- `faq.html`: perguntas frequentes sobre o sistema.
- `contatos.html`: formulário de contato com a equipe.
- `integrantes.html`: apresentação dos integrantes.
- `sobre.html`: informações sobre a ideia, a solução e a proposta do projeto.
